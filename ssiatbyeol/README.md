# 씨앗별 학부모 조사 (ssiatbyeol/)

카카오톡 릴레이 명단으로 하던 반복 조사(방학 급식 인원, 돌봄 지원, 날짜·시간별 참석 등)를 링크 하나로 받는 익명 조사 페이지입니다. 빌드 없는 정적 페이지이며 Firebase(Firestore + Authentication)에 저장합니다.

- 응답자: `ssiatbyeol/?s=조사ID` — 이름·연락처 없이 선택만 합니다. 익명 로그인 uid 하나당 응답 1건이며, 같은 기기에서는 답변을 다시 열어 고칠 수 있습니다.
- 관리자: `ssiatbyeol/` — Google 로그인 후 조사 만들기·수정·복제·마감·삭제·결과 확인.
- 문항 유형: 여러 개 선택 / 하나만 선택 / 항목별 인원수 입력(급식 신청 인원 등). 날짜·시간 선택지는 자동 생성 도우미로 만듭니다.
- 반복 조사: 목록에서 `복제`하면 같은 문항으로 새 조사가 만들어집니다. `급식·돌봄 예시로 만들기`는 방학 급식·돌봄 조사를 바로 만들어 줍니다.
- 의견란을 켜면 관리자만 읽을 수 있습니다. 연락처가 필요하면 응답자가 의견란에 스스로 적게 안내해 주세요.
- 검색 노출을 막았고(`noindex`), 링크를 아는 사람만 접속합니다.

## Firebase 설정 (한 번만)

이 저장소의 `waldorf/` 페이지가 쓰는 Firebase 프로젝트를 그대로 써도 되고, 새 프로젝트를 써도 됩니다. 컬렉션 이름은 모두 `ss_`로 시작해 서로 겹치지 않습니다.

1. Firebase 콘솔 > **Firestore Database**가 없으면 만들기
2. 빌드 > **Authentication** > 로그인 방법에서 **익명**과 **Google**을 사용 설정
3. Authentication > 설정 > 승인된 도메인에 `frpsy.github.io` 추가
4. 프로젝트 설정 > 내 앱(웹)의 `firebaseConfig` 값을 `ssiatbyeol/firebase-config.js`에 붙여 넣기
5. Firestore > 규칙 탭에서 **기존 규칙을 지우지 말고**, `ssiatbyeol/firestore.rules`의 `function` 2개와 `match` 블록 2개(`ss_admins`, `ss_surveys`)를 기존 `match /databases/{db}/documents { ... }` 안에 추가한 뒤 게시. (프로젝트를 새로 만들었다면 파일 전체를 붙여 넣으면 됩니다.)
6. Firestore에서 컬렉션 `ss_admins`를 만들고, **문서 ID를 관리자 Google 이메일**로 한 문서를 추가 (필드는 아무거나 1개). 이 목록에 있는 계정만 조사를 만들 수 있습니다.

`firebase-config.js`가 비어 있으면 이 브라우저에만 저장되는 체험 모드로 동작하니, 설정 전에 화면을 먼저 확인할 수 있습니다.

## 한계

- 익명이므로 누가 응답했는지, 중복 응답(다른 기기·시크릿 창)을 막을 수 없습니다. 기기당 1건만 보장합니다.
- 정원 제한(선착순 마감)은 지원하지 않습니다.
