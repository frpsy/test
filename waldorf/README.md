# 발도르프 단체주문 (waldorf/)

링크 하나로 이름과 수량만 받아 실시간 취합하는 주문 페이지입니다. 기본 주소(`waldorf/`)는 기존 얌샘김밥 주문판 그대로입니다.

## 김밥 말고 다른 주문판 추가

1. `waldorf/#admin`으로 한 번 열면 그 기기에서 관리자 카드가 보입니다(기존 방식 그대로).
2. 아래 "새 주문판 만들기"에 이름, 메뉴(한 줄에 `이름 가격`), 단위(개·잔 등)를 적고 만들면 `waldorf/?b=코드` 전용 링크가 생기고 복사됩니다.
3. 주문판이 2개 이상이면 화면 위쪽에 주문판 선택 버튼이 보입니다. 주문 마감·삭제·수정은 주문판마다 따로 동작합니다.
4. 메뉴를 고치려면 해당 주문판 링크를 `#admin`으로 열어 "이 주문판 수정"을 쓰세요. 이미 들어온 주문은 메뉴 이름이 같은 항목에 이어서 반영됩니다.

김밥 데이터는 기존 컬렉션(`w_*`)을 그대로 쓰고, 추가 주문판은 `wb/{코드}/…`에 저장되어 서로 섞이지 않습니다.

## 배포 시 꼭 할 일 (한 번만)

`waldorf/firestore.rules`가 바뀌었습니다. 이 기기의 관리자 카드에서 `관리자 규칙 복사`를 눌러 Firebase 콘솔 > Firestore > 규칙에 붙여 넣고 게시해야 새 주문판을 만들고 주문받을 수 있습니다. 게시 전에도 김밥 주문은 기존대로 동작합니다.
